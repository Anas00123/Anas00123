### 🔐 Deep Packet Inspection (DPI) System
> Full-stack network security system with real-time packet capture & threat detection

- Built with **Spring Boot REST API**, 4 Java interfaces & 15 JPA entity models mapped to MySQL
- Implemented **Layer-7 protocol detection** (HTTP, HTTPS/TLS, DNS, FTP, SSH) & TLS/JA3 fingerprinting
- **DNS tunnelling detection** using Shannon entropy scoring
- Signature-based threat detection with **REGEX/HEX/YARA** rules & auto-generated severity alerts
- Live HTML/JS dashboard with **Chart.js** polling REST API every 2 seconds
